# P4 · 意图预算与 http 两档返回

> 依据《升级计划》P1-4 的后半（per-intent 预算）、`学习.md` 5.2/5.4（两档返回 + 大输出落盘）。
> 本轮只动"预算怎么给"与"响应体回多少"，不动调度与数据模型。

---

## 1. 先把钱花在哪量清楚（run #22）

| 归属 | input token | 说明 |
|---|---|---|
| 目标拆解 1 轮 | 4,048 | 一次性 |
| planner 3 轮 | 55,944 | 其中 2 轮产出 **0 条意图**（在等依赖） |
| 意图 #120（6 次工具调用） | 27,740 | 顺路径 |
| 意图 #121（27 次工具调用） | 80,622 | **成本中心**：一次执行占全轮 48% |

两个结论：

1. **单个意图的上下文是主要成本**：每多一次工具调用，下一轮 prompt 就多一段（工具结果 + 模型自己的话）；
2. **planner 的空转轮不便宜**：两轮"0 意图"花掉全任务 18%。

顺带记一笔口径：`input_tokens` 里 83% 是 `cache_read`（命中前缀缓存），所以"168k"是**名义值**，
实际计费远低于此。对比不同方案时看"名义值的变化率"仍然有效，但别拿它当账单。

## 2. 改了什么

### 2.1 意图级预算（`add_intent.budget`）

planner 可以给一条方向定上限：

```json
{"max_turns": 10, "max_seconds": 600}
```

语义是**只能收紧**：`resolveBudget` 拿 `min(任务配置, 意图预算)`，配置是天花板。
越界值夹到 `1..50` 回合、`30..3600` 秒而不报错（预算是优化项，不该让执行失败）。
生效时写一条 system activity（可审计："这条为什么这么短"）。

撞到上限走既有的 settlement 收尾轮（`exhausted`），所以"预算小"不等于"白跑"。

prompt 里给了三档建议值：探索性 8/300、可深入 20/900、复核类 10/600。

### 2.2 http 两档返回

`http_request` 默认只回**前 4KB** 响应体，完整内容落盘并在 body 末尾给路径；
需要全文时传 `full=true`（按 `MaxOutput` 回）。

为什么单独一档：一个 200KB 的 HTML 按 30k 字符回给模型，一次调用就吃掉 1/5 个窗口，
而绝大多数判断（状态码/标题/表单/跳转）只需要前几 KB。

## 3. 验证

`go test ./... -count=1` 89 个用例全绿；`scripts/race.ps1 ./...` 零数据竞争。
新增用例：`TestResolveBudget`（8 个子用例：收紧/不放大/夹边界/坏 JSON）、
`TestResolveBudgetDefaultsWhenConfigEmpty`、`TestHTTPBodyHeadByDefaultFullOnDemand`
（9000 字节响应：默认 4096+指针、`full=true` 回全文且无指针）。

真实 run #24（同一 goal、同一靶场）：

| 指标 | #22（P2/P3 后） | #24（P4 后） |
|---|---|---|
| planner 轮次 | 3（其中 2 轮 0 意图） | 2 |
| 意图预算 | 未设置 | `{10 回合, 600 秒}` ×2 |
| HTTP 请求 | 27 | 16 |
| 输入 token（名义） | 168,306 | 107,352 |
| 规则命中 | 3/3 | 3/3 |
| 事实 / 结局 | 4 / done | 5 / done |

**但必须说清：这是 n=1，不能归因给本轮改动。** 预算只设了 10 回合（实际用了 9 和 12 次工具调用，
没有被掐），两档返回在这个 238 字节的靶场上也根本不触发。token 下降主要来自
"planner 少跑一轮、意图更聚焦"这种 run 间方差。要证明 P4 有效，需要同一批任务跑 ≥5 次取中位数，
并且换一个**响应体大**的靶场（否则两档返回永远不生效）。

## 4. 还没做

1. **worker 拿不到 `list_facts`**：并行意图会重复探测同一批路径（P0 修复后已从 9 个重复降到 1~2 个，
   但根因仍在 —— worker 看不到"别人已经测过什么"）；
2. **planner 空转轮没有退避**：一轮 0 意图、图也没变时，下一次唤醒照样全价重算；
3. **没有成本指标**：`TokenTotals` 只有总数，没有"每意图/每事实"的边际成本，也就没法做预算回归。
